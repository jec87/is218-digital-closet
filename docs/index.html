About My Project

My Digital Closet is a web application that helps college students and young adults organize their clothing, create outfits, and save their favorite combinations.

I chose this project because I wanted to combine my interest in design with programming and create something useful for everyday life.

Research Question

How can I build a secure, simple, and visually appealing digital wardrobe application using Python?

Target Audience

College students and young adults who want to organize their clothes and make choosing outfits easier.

Comparing Two Project Ideas

Option 1: Digital Closet

Users create accounts, add clothing items, combine them into outfits, and save outfits for later.

Option 2: Habit Tracker

Users create accounts, record daily habits, track their progress, and review their history.

My Decision

I chose Digital Closet because it offers more opportunities for creative interface design while allowing me to practice databases, authentication, and testing.

Planned Features

  1. Create an account and log in securely.
  2. Add and organize clothing items.
  3. Create outfits from saved clothing.
  4. Save outfits and view private history.
  5. Update account information.

Five User Stories

  1. As a user, I want to create an account so my wardrobe stays private.
  2. As a user, I want to add clothing items so I can organize what I own.
  3. As a user, I want to combine clothing items so I can create outfits.
  4. As a user, I want to save outfits so I can view them again later.
  5. As a user, I want to update my account information so I can manage my profile.

Facts, Interpretations, and Assumptions

Facts

Flask supports routing and templates. SQLite supports persistent data storage. pytest supports automated Python tests.

My Interpretation

Flask and SQLite appear to be a good combination for a small web application because they let me focus on learning application logic.

My Assumption

I think users may prefer seeing clothing items in a visual grid rather than a text-based list. This has not been tested with a working prototype.
