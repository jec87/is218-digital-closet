Development Research & Project Planning

IS218-003 | Review 1 | November 12, 2026

About My Project

My Digital Closet is a web application that helps college students and young adults organize their clothing, create outfits, and save their favorite combinations.

I chose this project because I wanted to combine my interest in design with programming. I also wanted to create something useful for everyday life.

Research Question

How can I build a secure, simple, and visually appealing digital wardrobe application using Python?

Target Audience

College students and young adults who want to organize their clothes and make choosing outfits easier.

Comparing Two Project Ideas

Option 1: Digital Closet

Users create accounts, add clothing items, combine items into outfits, and save outfits for later.

Option 2: Habit Tracker

Users create accounts, record daily habits, track their progress, and review their history.

My Decision

I chose Digital Closet because it offers more opportunities for creative interface design while still allowing me to practice databases, authentication, and testing.

Technology Stack

Python Flask SQLite HTML CSS pytest

Python and Flask

SQLite

Planned Features

  1. Create an account and log in securely.
  2. Add and organize clothing items.
  3. Create outfits from saved clothing.
  4. Save outfits and view private history.
  5. Update account information.

Five User Stories

  1. As a user, I want to create an account so my wardrobe stays private.
  2. As a user, I want to add clothing items so I can organize what I own.
  3. As a user, I want to combine clothing items so I can create outfits.
  4. As a user, I want to save outfits so I can view them again later.
  5. As a user, I want to update my account information so I can manage my profile.

Facts, Interpretations, and Assumptions

Facts to Verify

Flask provides routing and template functionality. SQLite supports persistent database storage. pytest supports automated Python tests.

My Interpretation

Flask and SQLite appear to be a good combination for a small web application because they allow me to focus on learning the application logic.

My Assumption

I think users may prefer seeing clothing items in a visual grid rather than browsing a text-based category list. This has not been tested yet.

Creative Experiment

Visual Grid vs. Category List

I want to compare two different ways of displaying clothing items.

Approach A: A visual grid showing all clothing items.

Approach B: A category-based list separating tops, bottoms, shoes, and accessories.
