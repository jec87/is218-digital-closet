
# My Digital Closet

## Project Overview

My Digital Closet is a web application that helps college students and young adults organize their clothing, plan outfits, and save their favorite combinations.

## Target Audience

College students and young adults who want a simple way to manage their wardrobe and plan outfits without feeling overwhelmed.

## Two Project Ideas

### Option 1: Digital Closet & Outfit Planner

Users can create accounts, add clothing items, create outfits, and save their favorite outfit combinations.

### Option 2: Habit Tracker

Users can create accounts, record daily habits, track their progress, and view their completed activities.

## Final Choice

I chose Digital Closet because it allows me to combine creative design with programming. I also think it would be useful for students who want to organize their clothes and save time choosing outfits.

This project will help me practice authentication, databases, testing, and user interface design.

## Technology Stack

- Python and Flask: Backend
- SQLite: Database
- HTML and CSS: Frontend
- pytest: Automated testing
- GitHub: Version control and documentation

## Planned Features

1. User registration and secure login
2. Add and organize clothing items
3. Create outfits using saved clothing
4. Save outfits and view private outfit history
5. Update account information

## Five User Stories

1. As a user, I want to create an account so my wardrobe stays private.
2. As a user, I want to add clothing items so I can organize what I own.
3. As a user, I want to combine clothing items so I can create outfits.
4. As a user, I want to save outfits so I can view them again later.
5. As a user, I want to update my account information so I can manage my profile.

The browser will display the website. Flask will handle user requests, authentication, and outfit creation. SQLite will store user accounts, clothing items, and saved outfits.

## Security and Privacy

- Passwords will be securely hashed.
- Users will need to log in to access their wardrobe.
- Users will only be able to view and edit their own clothing and outfits.
- Account information will be validated before updates.
